# loteria-cards

A play-along Lotería board for the iPad or phone. Someone calls from a real deck; you tap **Cantaron…**, pick the card, and it marks itself on every tabla where it appears.

- Pick the game each round: Clásico (4 in a row, 4 corners, or 4 in a square), or a single shape — La Equis, La Ele, El Marco, Rieles, Escalera, Centro, Siete Loco, Tabla Llena.
- Edit tablas square by square (doubles allowed, house rules), add up to six per person.
- Several people on one device, each with their own tablas; **Share** makes a link that carries a set of tablas to another phone.
- Everything is stored on the device. No accounts, nothing sent anywhere.

The whole app is `index.html`; the card images sit beside it.
